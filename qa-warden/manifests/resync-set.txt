# resync-set.txt — the ONE manifest of TOOLKIT-OWNED substrate files.
#
# Two consumers read this file; neither hand-enumerates the set any more:
#   - bin/qa-scaffold  --resync : force-refreshes exactly these files (backing each up to .qa-bak)
#   - skills/doctor/scripts/doctor.sh Check 9 : byte-compares exactly these files against the shipped templates
# Both read THIS copy, in the plugin. That is why it lives in manifests/ and not in templates/:
# bin/qa-scaffold stamps every file under templates/, and a stamped copy of this list was read
# by nothing — editing it in a project changed no behaviour and only fired a drift warning.
# claude-md-vocab.txt and prod-guard-rails.txt sit beside it for the same reason.
# Detection and repair MUST cover the SAME set (M-8): a file resynced but never drift-checked is
# silently repaired yet never NUDGES the user to run --resync; a file drift-checked but never
# resynced nags forever with no repair path. Two hand-kept lists could not hold that invariant —
# this file is the single source, so adding a template is a ONE-line edit here.
#
# Enumerated on purpose (not a find-walk of templates/): --resync is DESTRUCTIVE-with-backup, so
# it must touch only files with a SINGLE owner. Deliberately EXCLUDED, all shared-ownership:
#   .env / .env.example  — users extend them for seed vars (doctor's stock-var containment
#                          sub-check still catches a DELETED stock var)
#   CLAUDE.md            — users customize project policy
#   settings.json        — users add their own permission rules (jq-merged, never copied;
#                          doctor Check 9c covers the retired-rule case a union merge can't remove).
#                          NOT a gap: --resync runs that same merge via stamp_permissions(), so
#                          the rules travel with the files even though the FILE is not copied.
#   gitignore            — user-editable once stamped. --resync appends exactly one pattern to
#                          it, `*.qa-bak`, covering litter the resync itself writes — see
#                          ensure_qa_bak_ignored() for why that is the whole of the carve-out
#   fixtures/test.ts     — users wire their own fixtures
#   page-objects/README.md — user-authored notes land here
#
# Blank lines and `#` comments are ignored; blanks around a row and `./` segments in it are too.
# Both consumers read this file through ONE function, manifest_paths in the plugin's
# lib/manifest.sh, so they cannot parse a row differently (they once did: doctor trimmed and
# normalised rows that --resync took verbatim). Paths are relative to the project root and to
# templates/. Every line must name a file under templates/ — both consumers silently skip a
# line whose template does not exist. This file used to list ITSELF (and the two other plugin-
# only manifests) so that a change propagated; it no longer needs to, because a project never
# receives a copy. A project stamped before the move keeps an inert scripts/resync-set.txt,
# scripts/claude-md-vocab.txt and scripts/prod-guard-rails.txt; doctor names them as safe to
# delete.
# scripts/doctor.sh below is the stamped LAUNCHER (it finds the installed plugin and runs its
# skills/doctor/scripts/doctor.sh). The checks themselves ship in the plugin and are not listed.
#
# PROTECTION TIER — the second column of every row. It says how the stamped file is guarded
# against an agent editing it in place (doctor Check 9's header tells the history):
#   deny    an `Edit(...)` rule in templates/settings.json deny[] covers the path (an exact path
#           or a glob); the edit is blocked outright. A path under an allow glob such as
#           Edit(specs/**) or Edit(fixtures/**) is still `deny`: its deny is per-path and does
#           NOT follow from the tree, which is why it has to be declared here.
#   prompt  deliberately NOT denied and under no Write/Edit allow glob, so every edit is
#           approved by a human at the prompt. These are files a user may legitimately need to
#           touch on the spot (init.sh, the README, the two stamped data manifests, the nightly
#           workflow example). Not a gap.
# bin/qa-selfcheck Check 9f arm 4 holds this column against templates/settings.json: a `deny`
# row no Edit deny covers, a `prompt` row that is denied or sits under an allow glob, and a row
# with no tier (or any other word) all fail. Every reader other than that check takes the path
# column only.
