## 1. What this plugin is

A Claude Code plugin (`qa/`) for AI-authored, Playwright-replayed E2E testing.
Thesis: AI authors specs + tests, Playwright replays nightly at ~$0 LLM cost, AI triages
only on failure. Claimed moat = the **oracle-defense layer** (closed 16-key assertion
vocabulary, metamorphic twins, fault injection, blocking reviewer) that Microsoft's official
Playwright Agents deliberately do not provide.

Layout: 6 agents, 23 skills (19 user-facing + 4 capability helpers), `templates/` runtime
substrate stamped by `/qa:init`, `reference/` docs, `bin/qa-scaffold`.

### B1 — Healer cannot execute its own process ⛔
`healer.md:160` sets **"Hard budget: 5 turns per failure."** Mirrored in
`templates/CLAUDE.md:259` and `skills/heal/SKILL.md:50`.
Documented 7-step process needs **≥14 turns**: prod-guard (1) + five-command trace sequence
`healer.md:48-52` (5) + 2 Reads + error-context (1) + Edit (1) + re-run (1) + the mandated
**two separate** consumer calls `:91` (2) + telemetry (1).
Effect: takes the budget-exhausted arm (file bug + revert) on **every** failure, logging a
plausible `escalated` outcome so nothing surfaces it.
**Fix:** prose budget 5 → 14; `maxTurns` 20 → 24 (preserves the documented 4-turn fallback
floor at `healer.md:162`). Update all three files together.

## 9. Strategic conclusions (context for Block 3, no action needed)

**The moat holds.** Microsoft's shipped agent definitions (pulled from
`microsoft/playwright@main`, not blogs) instruct their healer verbatim: *"mark this test as
`test.fixme()` so that it is skipped"* and *"Do not ask user questions... do the most
reasonable thing possible to pass the test."* No reviewer, no approval gate, no fault
injection anywhere in their chain. Their healer ships the exact green-but-wrong failure mode
this toolkit's reviewer exists to block.

Research backing: LLM oracle correctness **<50%**; oracles cause **~89%** of errors in
LLM-generated tests; LLMs **follow the implementation over the spec** when code is buggy.
A 2026 replication study (11 models, >100k test cases) found coverage/mutation correlations
**invert on buggy code**, and mutation testing becomes *inapplicable* (needs a passing suite).
That is the strongest argument for fault injection: direct bug-detection measurement that
works in the regime where standard proxies don't.

**Two erosions to stay honest about.** MS's `--caps=testing` now ships a closed **4-verb**
assertion vocabulary — closed vocab is becoming table stakes; the lead is 16-vs-4 plus
negative/`must_fail_when` semantics, a lead in degree not kind. And metamorphic twins for
browser E2E are genuinely novel (research is nearly all REST APIs / autonomous driving) —
expect to explain, not cite.

**Verdict: don't re-shape the architecture; re-shape the emphasis.** What's exposed is not
the moat but **breadth and enforcement** — the gate is prose rather than a hook, and two
SFDIPOT lenses (Interfaces/Operations, Time) can't be generated against for lack of network
interception and `page.clock`.

**Model-pin rationale (Block 2).** `DESIGN.md:246-249` splits on "failure surfaces as a red
test" vs "failure is a silently missing finding" — sound, but it misclassifies the planner.
The planner authors the oracle, and `DESIGN.md:368-374` concedes nothing downstream compares
the oracle to reality. Every planner judgment call fails silently. `DESIGN.md:251-252` calls
the planner "the durable fix" for the reviewer's weakest gate while pinning it a tier *below*
the reviewer — inverted. It is also the cheapest agent to upgrade (10-turn budget, 3 reads,
1 write, no browser loop). Note also: **a pin lowers the ceiling too** — an operator running
`claude --model opus` then `/qa:gen` gets a sonnet generator; `DESIGN.md:236` argues only the
"raises the floor" half. And only the reviewer carries the A-04 org-allowlist advisory;
ideation's opus pin is equally load-bearing and has none.

**Generator split rationale (Block 3).** The decisive argument isn't size (298 lines) — it's
that **the same agent that writes the `expect()` decides whether that `expect` catches the
defect** (steps 8b/8c). Its cheapest path is to claim CATCHES, and the resulting `// verified:`
comment becomes durable evidence reviewer Check 2b trusts. An author-independent verifier is
a real epistemic improvement to the toolkit's own core defense. It also fixes the generator's
budget overrun (~20 turns minimum against a 15-turn prose budget / 22 `maxTurns`).
